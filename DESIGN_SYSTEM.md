# DESIGN_SYSTEM.md — YggGram Visual & Interaction Design System

## 1. Design Philosophy: Obsidian & Emerald Luxury (Telegram Desktop × Linear)

YggGram сочетает бескомпромиссную конфиденциальность с эстетикой современного премиального программного обеспечения. Интерфейс вдохновлен точностью **Linear**, тактильностью **Telegram Desktop** и киберпанк-минимализмом децентрализованных систем.

### Ключевые принципы:
1. **Zero-Latency Feel (Ощущение нулевой задержки):** Мгновенная реакция UI на ввод, оптимистичный рендеринг отправляемых сообщений, аппаратное ускорение анимаций.
2. **Information Density without Clutter:** Высокая плотность информации для десктопа (компактные списки, четкие моноширинные хэши и адреса) и просторные зоны взаимодействия для сенсорных экранов Android.
3. **Hardware & Stealth Aesthetics:** Темная тема «Obsidian Dark» с акцентами электрического изумруда (`#00E5A3`) и кибер-циана (`#00D2FF`). Никакого детского неонового перегруза или шаблонного Material Design.
4. **Adaptive Contextuality:** Единый кодовый базис на Flutter плавно масштабируется от ультраширокого монитора (3-4 колонки) до узкого экрана смартфона с жестовой навигацией.

## 4. Layout Architecture: Adaptive Multi-Column

### 4.1 Windows Desktop (> 900px Width)
Трехколоночная компоновка по канонам Telegram Desktop:
```
+----+----------------------+------------------------------------+------------------+
| F  |      Chat List       |            Active Chat             |   Media/Drawer   |
| o  |                      |                                    |                  |
| l  | [Search / Filters]   | Header (Peer IPv6, Anti-DPI radar) | Shared Media     |
| d  | -------------------- | ---------------------------------- | Encryption Keys  |
| e  | Alice      14:22 [2] | Messages stream (E2EE bubbles)     | Session Ratchets |
| r  | Bob (Direct P2P)     |                                    | S&F Mailbox Info |
| s  | Channel: Dev Updates | Input Bar (Attaches, Audio, Send)  |                  |
+----+----------------------+------------------------------------+------------------+
  64px        320px                          Flexible                      300px (collapsible)
```
- **Кастомный Titlebar:** Тонкий заголовок окна в стилистике Win32 (`window_manager`) с кнопками свернуть/развернуть/закрыть и статусом Yggdrasil-узла в центре.
- **Шорткаты:** `Ctrl + K` (быстрый переход к чату), `Ctrl + F` (поиск по зашифрованной базе FTS), `Esc` (закрытие боковой панели), `Ctrl + N` (новый диалог).
- **Системный трей:** Сворачивание при закрытии окна, бейдж непрочитанных сообщений, контекстное меню быстрого статуса сети.

### 4.2 Android Mobile (< 900px Width)
- **Полноэкранный компактный режим:**
  - Плавный стек-навигатор (`CupertinoPageRoute` / Hero transitions).
  - Управление жестами: свайп вправо в чате для ответа (`Swipe-to-Reply`), свайп от левого края для возврата в список.
  - Удобная нижняя зона досягаемости пальца: строка ввода, запись голосового сообщения с блокировкой свайпом вверх, вызов вложений.

## 5. Component Specifications

### 5.1 Message Bubbles
- **Входящие:** Фон `#161D28`, радиус скругления 12px (левый нижний угол 4px), тонкая рамка `#1F2937`.
- **Исходящие:** Градиент от `#0E3D30` до `#083226` с акцентной каймой `#00E5A3`, радиус 12px (правый нижний угол 4px).
- **Индикаторы доставки:**
  - Одиночная серая галочка: принято локальным Go-ядром / S&F релеем.
  - Двойная изумрудная галочка: расшифровано получателем по Double Ratchet.
  - Замочек с капсулой: статус E2EE (X3DH / MLS).

### 5.2 Anti-DPI Radar Header Widget
В шапке каждого диалога и в глобальном статусе отображается индикатор качества соединения:
```
[● DIRECT P2P] 200:4f2a:... (12ms) | uTLS: Chrome 130 | Loss: 0%
```
- Зеленый пульсирующий диод при прямом P2P по QUIC.
- Желтый значок «Облачный шлюз» при работе через Store-and-Forward релей.
- Синий бейдж «WSS CDN» или «ShadowTLS» при активном анти-DPI обходе блокировок.

### 5.3 Media & Attachments
- **BlurHash:** Моментальный рендеринг заблюренного плейсхолдера с точными пропорциями изображения до расшифровки P2P-чанков.
- **Progress Circle:** Круговой индикатор загрузки с отображением количества скачанных чанков роя (`14/32 chunks`).
- **Аудио-сообщения:** 32-полосный тактильный вейвформ с плавным заполнением изумрудным цветом при воспроизведении.

## 6. Micro-Interactions & Haptics

1. **Анимации:** Все переходы длятся **180–220 мс** с кривой `Curves.easeOutCubic`. Никаких затянутых или пружинящих мультяшных эффектов.
2. **Тактильный отклик (Android):**
   - Легкий виброотклик (`HapticFeedback.lightImpact()`) при свайпе для ответа.
   - Четкий щелчок (`HapticFeedback.mediumImpact()`) при отправке сообщения и блокировке записи аудио.
   - Предупреждающий отклик (`HapticFeedback.selectionClick()`) при копировании публичного ключа или мнемонической фразы.
3. **Безопасность экрана:** Автоматическое включение флага `FLAG_SECURE` на Android в окне просмотра мнемоники BIP-39 и секретных чатов для предотвращения скриншотов.
